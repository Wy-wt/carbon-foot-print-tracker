# 个人碳足迹计算器

帮普通人算出自己一年排多少碳、在什么水平、怎么减下来。
纯前端实现，无需后端、无需安装，**双击 `index.html` 就能用**。

---

## 一、怎么运行

| 方式 | 操作 |
|------|------|
| 最简单 | 双击 `index.html`，用浏览器打开 |
| **只想要一个文件** | 用 `standalone.html`：CSS / JS 全部内联，单独一个文件拷到哪里都能跑 |
| 本地服务器（可选） | 在 `carbon-footprint` 目录执行 `python -m http.server 8000`，访问 `http://localhost:8000` |

> `index.html` 依赖同目录下的 `assets/`（样式和脚本）；`standalone.html` 是它的**单文件版**，内容完全一样，只是把 `assets/css/style.css` 和 4 个 JS 内联进了 `<style>` / `<script>`。
> 部署到静态托管时，如果只能传一个文件、或者嫌麻烦，直接传 `standalone.html` 并改名为 `index.html` 即可。
>
> 图表优先使用 CDN 上的 ECharts；如果断网或加载失败，会自动降级为内置的原生 SVG/HTML 图形，功能不受影响。
> 历史记录存在浏览器 `localStorage` 里（换浏览器/清缓存会丢），没有任何数据上传。

`screenshots/` 里是实际渲染出来的结果页与手机版预览。

## 二、分享给别人 / 用手机看

> 临时隧道地址（形如 `https://xxxx.lhr.life`）**随进程结束即失效**，只适合当场演示；要长期链接请用方式 B / C。

这是一份纯静态站点，**没有任何后端**，所以只要「把文件夹放到一台能访问的服务器上」就行。三种做法，按场景选：

### 方式 A：临时公网隧道（不用注册，今天就能发出去）

```bash
# 1) 先把站点跑起来
python -m http.server 8000 --bind 0.0.0.0

# 2) 再开一条 SSH 反向隧道，把本机 8000 映射到公网
ssh -T -R 80:127.0.0.1:8000 nokey@localhost.run
```

终端会打印形如 `https://xxxxxxxx.lhr.life` 的地址，发给谁都能打开。

- ⚠️ **必须写 `127.0.0.1`，不要写 `localhost`**：Windows 上 `localhost` 优先解析到 IPv6 的 `::1`，而 Python 只监听了 IPv4，隧道就会一直返回 502，看起来就像「网站打不开」。这是最容易踩的坑。
- ⚠️ 隧道跟着进程活，关窗口 / 关机即失效；地址每次重连都会变。
- 校园网开了「终端隔离」时，直接用 `http://局域网IP:8000` 是打不开的，只能走隧道或方式 B。

### 方式 B：Netlify Drop 拖拽上传（要一个长期链接就选它）

1. 打开 <https://app.netlify.com/drop>（若要求登录，用 GitHub 或邮箱免费注册一个）
2. 把 **整个 `carbon-footprint` 文件夹**（不是只拖 `index.html`）或 `碳足迹计算器.zip` 拖进去
3. 几秒后得到一个 `https://xxx.netlify.app` 的公网地址，永久有效、任何人可访问

> **部署后页面「没有样式」怎么办？** 99% 是资源没传上去，`assets/css/style.css` 返回 404。常见三种原因：
> 1. 只拖了 `index.html` 一个文件 —— CSS/JS 都在 `assets/` 里，必须整个文件夹一起传；
> 2. 用的是 Windows 自带「发送到 → 压缩(zipped)文件夹」打的包，zip 内部路径是反斜杠 `assets\css\style.css`，Linux 托管平台解出来就成了一个叫 `assets\css\style.css` 的怪文件 —— 用仓库里的 `碳足迹计算器.zip`（已用正斜杠重新打包）；
> 3. 浏览器缓存了旧版本 —— Ctrl+F5 强刷，或用无痕窗口确认。
>
> 想彻底绕开：把 `standalone.html` 改名为 `index.html` 单独上传，它把 CSS/JS 全部内联了，**一个文件就是整站**。

### 方式 C：GitHub Pages / Cloudflare Pages / Vercel

适合想留个仓库、以后继续改的情况：把整个目录推到 GitHub 仓库，仓库 Settings → Pages → 选 `main` 分支根目录，就能拿到 `https://用户名.github.io/仓库名/` 的地址。三者流程类似，全是免费额度。

> 分享小提示：微信里直接点 `https` 链接一般能正常打开；二维码图片可以扫码，也可以直接发到群里。

## 四、功能对照（对应《功能清单》）

### 核心功能

- [x] **引导首页**：一句话定位 + 数据背景（居民生活消费碳排放约占全国 30%）+「开始计算」按钮 + 三条基准线数字
- [x] **分项输入**：出行（方式 / 通勤里程 / 其他里程）、用电（月用电量或按人数估算 / 家庭人口）、饮食（红肉次数 / 外卖次数 / 饮食倾向）、日常消费（衣物、电子产品年支出，可填 0）
- [x] **计算引擎**：排放因子法，`总排放 = Σ(活动量 × 排放系数)`
- [x] **结果页**：大号数字显示「你一年排放 X 吨」+ 等级勋章 + 与全国人均 / 全球人均 / 巴黎协定目标三条基准线的对比结论
- [x] **可视化**：分项占比**环形图**（ECharts）+ 与基准线对比的**条形图**（ECharts），另附明细拆解表（带占比进度条）
- [x] **减排建议**：根据各分项占比动态生成 5 条，每条附「一年可减 X kg」并给出合计效果

### 加分功能

- [x] **减排模拟器**：5 个滑块（通勤改公共交通比例 / 红肉次数 / 外卖次数 / 月用电量 / 衣物支出），**实时重算**总量、减排量、等级与「距巴黎目标还差多少」
- [x] **碳足迹等级勋章**：A+ / A / B / C / D 五档 + 分享卡片（Canvas 绘制，可下载 PNG）
- [x] **历史记录**：`localStorage` 保存最近 30 次结果，带趋势折线图、单条删除、一键清空
- [ ] **全国/地区对比**：未做（缺乏可核查的分省居民消费数据，避免编造）

### 明确不做

- 用户注册登录
- 实时天气 / 电网数据接口

## 五、关键算法（评分表：输入项 — 系数 — 依据）

**核心公式**：`总排放 = Σ(活动量ᵢ × 排放系数ᵢ)`，家庭用电按人口平摊：`人均用电 = 家庭月用电 × 12 ÷ 家庭人口`。

| 类别 | 输入项 | 单位 | 排放系数 | 依据 / 说明 |
|------|--------|------|----------|-------------|
| 出行 | 燃油私家车 | km | 0.20 kg CO₂e/km | 百公里油耗约 7 L，汽油 2.3 kg CO₂/L |
| 出行 | 新能源私家车 | km | 0.10 | 百公里电耗 17 kWh × 电网因子 0.5703 |
| 出行 | 打车 / 网约车 | km | 0.16 | 含空驶与调度，略低于私家车 |
| 出行 | 公交 | 人·km | 0.045 | 城市客运平均载客率折算 |
| 出行 | 地铁 | 人·km | 0.032 | 城市轨道客运平均 |
| 出行 | 电动自行车 | km | 0.007 | 百公里电耗约 1.2 kWh |
| 出行 | 步行 / 骑行 | km | 0 | 不计入直接排放 |
| 用电 | 家庭用电 | kWh | 0.5703 | 全国电网平均 CO₂ 排放因子 |
| 用电 | 按人数估算 | 户 | 68~120 kWh/人·月 | 1~6 人户阶梯估算，人越多人均越低 |
| 饮食 | 红肉 | 次 | 2.0 | 每次 150 g × 混合红肉 13.3 kg CO₂/kg（牛 27、猪 6、羊 20 加权） |
| 饮食 | 外卖 | 次 | 0.45 | 餐盒、包装、配送与额外食物浪费 |
| 饮食 | 基础饮食 | 年 | 560 / 700 / 950 | 以植物为主 / 荤素均衡 / 以肉为主 |
| 消费 | 衣物 | 元/年 | 0.06 | 纺织服装按消费额折算（含生产与运输） |
| 消费 | 电子产品 | 元/年 | 0.04 | 按消费额折算（含生产制造） |

**权重设计**：四类之间没有人为加权，全部由「活动量 × 系数」自然决定占比；`权重 = 分项排放 ÷ 总排放`，即环形图的百分比。改变某项活动量，其权重随之变化 —— 这也是减排建议「挑占比高的项优先给方案」的依据。

**三条基准线**（kg CO₂e / 人 / 年）

| 基准 | 数值 | 含义 |
|------|------|------|
| 全国人均 | 8.0 t | 中国能源相关 CO₂ 人均排放 |
| 全球人均 | 4.7 t | 全球平均 |
| 巴黎协定目标 | 2.0 t | 1.5℃ 情景下 2050 年人均需 ≤ 2 吨 |

**等级划分**：≤2.0 t → A+（气候先锋）；≤3.5 t → A（低碳生活家）；≤5.0 t → B（中等排放）；≤8.0 t → C（偏高排放）；>8.0 t → D（高排放）。

**口径声明**：本工具只统计居民生活消费直接相关的四类活动，不含公共服务、政府支出与工业中间投入，因此通常低于「全国人均」这类全口径数据；比较时应理解为「你的生活方式在人群中的相对水平」。系数取整后用于科普演示，不作为碳核算或交易依据。

## 六、验证用例

用无头 Chrome 实际跑通的几组数据（可与手算核对）：

| 场景 | 输入要点 | 结果 |
|------|----------|------|
| 标准城市青年 | 地铁 40 km/周、月电 240 度/3 人、红肉 4 次、外卖 3 次、衣物 3000、电子 2000 | 约 **2.09 t**，等级 A |
| 开车通勤族 | 燃油车 100 km/周 + 其他 40 km、月电 320 度/3 人、红肉 6 次、外卖 5 次、以肉为主、衣物 6000、电子 5000 | 约 **4.44 t**，等级 B |
| 模拟器验证 | 上一行数据把通勤 100% 改公共交通 → 红肉降到 0 → 月电降到 60 度 | 4.44 → 3.21 → 2.59 → **2.00 t**，等级 A+ |

手算核对（第二行）：
`通勤 100×52×0.2 = 1040`，`其他出行 40×52×0.2 = 416`，`用电 320×12÷3×0.5703 = 730`，
`饮食 950 + 6×52×1.995 + 5×52×0.45 ≈ 1689`，`消费 6000×0.06 + 5000×0.04 = 560`，合计 **4435 kg ≈ 4.44 t**。
